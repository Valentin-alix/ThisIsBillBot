# Interface settings

[Back to the README](../README.md)

The **Settings** page contains the following sections:

| Section | Settings |
| --- | --- |
| Behaviors | Activities to automate. |
| Email | Mailboxes used by automation. |
| Proxies | Proxies available to accounts. |
| Schedules | Daily time slots. |
| Accounts | Account-to-profile assignments. |
| Services | Sonji API key. |
| Payments | Paysafecard codes. |

Behavior changes take effect the next time the bot starts. Account automation
settings take effect at the next operation without interrupting the current one.
Manual email codes are entered in a confirmation dialog.
